## 何时记录

| 触发场景 | 是否记录 |
|---|---|
| 需求分析文档新增 / 冻结 / 变更 | ✓ |
| 实施 / 优化方案文档新增 / 确认 / 变更 | ✓ |
| 用户手册新增 / 更新 | ✓ |
| 字典（系统字典、错误码字典）变更 | ✓ |
| BUG 记录归档（已修复） | ✓ |
| 通用规范（`docs/00_通用规范/`）变更 | ✓ |
| 工作流（`docs/10_工作流程/`）变更 | ✓ |
| README / 内部说明类调整文字 | ✗ |

## 记录格式

```
## yyyy-mm-dd

- [类型] 简述变更 —— 文件路径 —— 操作人
```

类型枚举：
- `新增` —— 新建文档
- `更新` —— 修改已有文档
- `冻结` —— 文档定稿
- `废弃` —— 文档已不适用，但保留
- `删除` —— 文档永久删除（极少）
