# 表格板块相关规则

> 凡是涉及到有表格元素的页面，都应该遵守本规则

- 表格标题居中，支持伸缩列
- 表格内的数字应当在单元格右对齐
- 表头冻结。表格应当占满页面剩余空间，但不得超出视图。
- 如果有操作列的表格，操作列需要固定。
- 时间字段统一使用 `yyyy-MM-dd HH:mm:ss` 格式展示，**禁止**自行 `replace('T',' ').slice(0,19)` 或重复封装；统一调用 `@vben/utils` 暴露的 `formatDateTime`（基于 dayjs，自带时区与无效值兜底）。
  - 仅日期使用 `formatDate(value, 'YYYY-MM-DD')`；
  - 空值占位统一使用 `—`（em dash）。

## 时间列推荐写法

```ts
import { formatDateTime } from '@vben/utils';

// ant-design-vue Table
const columns = [
  {
    title: '创建时间',
    dataIndex: 'createdAt',
    width: 180,
    customRender: ({ text }: { text?: string }) =>
      text ? formatDateTime(text) : '—',
  },
];

// vxe-table（在 vxe-table.ts 适配器统一注册 formats / cellRender）
// columns: [{ field: 'createdAt', title: '创建时间', formatter: ({ cellValue }) => cellValue ? formatDateTime(cellValue) : '—' }]
```

**反模式：**

- ❌ 在每个页面手写 `s.replace('T', ' ').slice(0, 19)`；
- ❌ 在业务页面引入 `dayjs` / `moment` 仅为了格式化时间；
- ❌ 后端二次序列化为时间戳 long 后再前端 `new Date()` 处理。
