# 05 · 回归用例

> 本目录**永久保留**所有有价值的回归用例。
> 每个用例都是一道"防止历史 BUG 复发"的栅栏。

---

## 组织方式

按模块建子目录：

```
docs/05_回归用例/
├── README.md
├── 用户模块/
│   └── 回归用例.md
├── 订单模块/
│   └── 回归用例.md
├── 支付模块/
│   └── 回归用例.md
└── E2E/
    └── 核心业务流.md
```

> 项目体量小可不分模块，直接把所有回归用例放一个 `回归用例.md` 即可。

---

## 用例最小要素

每条用例包含：
- 用例编号（`TC-REG-<模块>-<序号>`，例：`TC-REG-USER-007`）
- 来源（关联的 BUG / 方案 / 需求 ID）
- 前置条件
- 操作步骤（编号化）
- 预期结果（**具体断言点，禁止"看起来对"**）
- 优先级（P0/P1/P2/P3）
- 自动化级别（手工 / 半自动 / 自动）
- 自动化测试代码位置（如已自动化）

---

## 何时新增用例

- **每个 BUG 修复**：必新增至少 1 条（防复发）
- **每个新功能/优化**：从方案文档"测试用例"小节挑选 P0/P1 拷贝过来
- **每次回归发现的新场景**：补一条

---

## 用例格式示例

```markdown
### TC-REG-USER-007（防止历史 BUG 20260506）

- **来源**：BUG-20260506-角色管理分配权限抽屉数据丢失
- **前置**：已登录管理员账号；存在角色"测试角色"
- **步骤**：
  1. 角色管理列表 → 点击"分配权限"按钮
  2. 抽屉弹出，勾选 3 个权限节点
  3. 不关闭抽屉，再次点击同行"分配权限"
- **预期**：
  - 抽屉重新打开后**保留**上一次未保存的勾选状态
  - 控制台无 `defineModel` 相关警告
- **优先级**：P1
- **自动化**：未自动化（手工）
```

---

## 维护规则

- 用例**只增不删**，已修复 BUG 的回归用例永久保留
- 用例过期（功能已下线、规则已变）：标记 `[已废弃]` 但不删除
- 自动化后保留人工描述，并补"自动化代码位置"
