# 02 · 功能设计

> 本目录存放每个功能的实施/优化方案设计文档。
> **方案未确认前禁止开始开发。**

---

## 命名规则

```
<功能简称>_实施方案_yyyymmdd.md          # 新功能
<功能简称>_优化方案_yyyymmdd.md          # 优化升级
<功能简称>_重构方案_yyyymmdd.md          # 重构
```

例：
- `用户角色管理_实施方案_20260513.md`
- `订单导出_优化方案_20260520.md`

---

## 文档来源

复制 `docs/20_模板/实施方案设计模板.md`，填写后归档到此目录。

参考样例：`docs/20_模板/_示例_实施方案_用户登录.md`

---

## 写完后的去向

- 状态从"草稿"→ 评审 → **得到开发者明确确认**才进入"已确认"
- 进入对应工作流的开发步骤
- 文档更新记入 `docs/文档更新日志.md`
- 开发完成后，回填"实施结果"小节（实际工作量、偏差原因、指标对比）

---

## 与需求分析文档的关系

```
需求分析（What） → 实施方案（How） → 开发（Build）
docs/01_需求分析/    docs/02_功能设计/    代码
```

实施方案文档**必须**在"元信息"小节回填"关联需求"路径。
