# 01 · 需求分析

> 本目录存放每个需求的需求分析文档。
> **每次启动新功能开发/优化升级工作流的第一个产出物。**

---

## 命名规则

```
yyyymmdd_<功能简称>需求分析.md
```

例：
- `20260513_用户角色管理需求分析.md`
- `20260520_订单导出优化需求分析.md`

---

## 文档来源

复制 `docs/20_模板/需求分析模板.md`，填写后归档到此目录。

参考样例：`docs/20_模板/_示例_需求分析_用户登录.md`

---

## 写完后的去向

- 状态从"草稿"→ 经过开发者/产品确认 → 改为"已冻结"
- 进入 `100_新功能开发工作流程.md` 第 (2) 步：方案设计
- 文档更新记入 `docs/文档更新日志.md`

---

## 检索建议

- 按时间倒序排列
- 在文件名中带功能简称便于 grep
- 大模块（如"用户中心"）可建子目录归档相关文档
