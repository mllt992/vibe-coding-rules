# 列表页设计规范

> 适用范围：所有"管理类"列表页（用户、角色、字典、组织、业务对象等）。
> 关联规范：
>
> - 实现层：[`列表页表格自适应规范.md`](./列表页表格自适应规范.md)（高度链、`useTableHeight`、可伸缩列、验收 checklist）
> - 组件层：`组件_搜索组件要求.md`、`组件_表格组件要求.md`、`组件_导出组件要求.md`
> - 框架层：`前端页面开发规范.md`
>
> 本文档定义**视觉/交互/数据**侧的统一约束；高度链、`scroll.y`、列伸缩等**实现细节**全部委托给自适应规范，二者不重复、不冲突。

---

## 1. 四段式布局

每个列表页**自上而下**严格遵循四段，**每段独立 Card**，分页**不得**嵌在表格 Card 内：

```
┌─────────────────────────────────────────────┐
│  Card · 搜索板块（.search-panel）            │
│   每个控件带 label；查询/重置按钮位于尾列     │
├─────────────────────────────────────────────┤
│  Card · 工具栏（.tool-panel）                │
│   左：[新增] [批量操作...]                  │
│   右：[导入] [导出] [刷新]                   │
├─────────────────────────────────────────────┤
│  Card · 表格（.table-panel）                 │
│   flex:1 占满剩余高度；表头冻结/操作列固定   │
│   a-table :pagination="false"               │
├─────────────────────────────────────────────┤
│  Card · 分页（.pager-panel）                 │
│   左：共 N 条；右：a-pagination（外置）      │
└─────────────────────────────────────────────┘
```

约束：

- 不得省略其中任何一段；树形管理页例外见 §5。
- 不得把不同段落的内容混入同一 Card（如把分页塞进表格 Card、把工具栏控件放到搜索板块）。
- 四个 Card **不要套在一个外层 Card 内**；它们是 `.page` 容器的直接子节点，受 flex 高度链管理（详见自适应规范 §2）。
- 各 Card 之间统一 `gap: 12px`；首/尾不再额外 margin。

## 2. 工具栏布局

- **左侧（左对齐）**：
  1. 新增按钮（`type="primary"`）
  2. 批量操作按钮 / 下拉（仅对支持批量选择的列表存在），紧随新增按钮之后；
- **右侧（右对齐）**：
  1. 导入按钮
  2. 导出按钮
  3. 刷新图标按钮（可选，`<a-button shape="circle">`）
- 工具栏使用 `display:flex; justify-content:space-between`，**禁止**用 `flex:1` 撑高度（与自适应规范 R5 冲突）。
- 没有"导入/导出"能力的页面右侧可留空，**不要**把"新增"挪到右侧。

## 3. 表格区

表格区是四段中**唯一会随视口高度伸缩**的一段，必须遵循自适应规范：

| 要求 | 来源 |
| --- | --- |
| `.table-panel` 必须 `flex: 1 1 auto; min-height: 0; overflow: hidden` | 自适应规范 §2.2 R2 / §3.1 |
| `a-table :scroll="{ x: <列总宽>, y: tableY }"` | 自适应规范 §4.1 |
| `a-table :pagination="false"`（分页**必须**外置） | 自适应规范 §4.1 / FAQ Q2 |
| `tableY` 通过 `useTableHeight(wrapperRef, { headerHeight, reserved })` 计算 | 自适应规范 §3.2 |
| 列伸缩（如需）通过 `useResizableColumns` + `ResizableHeaderCell` 接入 | 自适应规范 §6 |

视觉约束：

- 表头冻结；操作列固定到右侧（`fixed: 'right'`）；
- 数字、金额列右对齐；状态、操作列居中；其他默认左对齐；
- 单元格内容超出使用 `ellipsis: true` + tooltip，**不允许**强制换行撑高行高；
- 空态：数据为空时表格仍占满剩余空间，"暂无数据" 居中。

## 4. 分页

分页统一**外置**为独立 Card（`.pager-panel`），**禁止**使用 `a-table` 内置分页。

```vue
<section class="panel pager-panel">
  <span class="pager-info">共 {{ total }} 条</span>
  <a-pagination
    v-model:current="pagination.current"
    v-model:page-size="pagination.pageSize"
    :total="total"
    :page-size-options="['10', '20', '50', '100']"
    show-size-changer
    show-quick-jumper
  />
</section>
```

约束：

- `showSizeChanger`、`showQuickJumper` **必开启**；
- `pageSizeOptions` 默认 `['10','20','50','100']`；
- 默认 `pageSize` 推荐 20（用户/字典等高频）或 10（信息密集列表）；
- 左侧 `共 N 条` 由自定义 `<span>` 渲染（外置后不能用 `showTotal`），右侧为 `a-pagination` 主体；
- 后端分页协议保持 `{records, total, page, size}` 单一来源；
- 前端字段名与后端约定一致（用户/角色：`page/size`；字典：`page/pageSize`），**不在前端做"重命名"**。

## 5. 树形管理页（菜单/组织等）

- **不强制四段中的"分页"段**；其余三段（搜索 / 工具栏 / 表格）保留，结构与高度链照常；
- 推荐 **左树 + 右详情** 双栏布局：左树撑满 `.table-panel` 高度，搜索关键字以**本地过滤**为主；
- 搜索板块可比普通列表更精简（单关键字 + 状态/类型）。

## 6. 状态管理

- 搜索条件、分页 state 使用 `reactive` 维护；
- 列表 `loading`、`dataSource`、`total` 三个 ref 必须显式声明；
- 每次 `查询` / `重置` / `分页` / `pageSize 变更` 都调用统一的 `fetchData()`；
- 使用 `keep-alive` 时，如表格区在重新激活后尺寸异常，在 `onActivated` 中触发 `measure()`（自适应规范 §5.2）。

## 7. 数据请求

- 仅传非空参数；空字符串 / `undefined` / `null` 一律省略；
- 远端选项（如"角色筛选"下拉）在 `onMounted` 中加载一次，最大 200 条以内（受 `size` 上限约束）；
- 表格请求开始 → `loading=true`；结束（成功/失败/取消）→ `loading=false`，不允许跳过 `loading` 态。

## 8. 高危操作

- 删除走 `Popconfirm` 或 `Modal.confirm`，二次确认；
- 批量删除展示影响行数；
- 操作列固定到右侧（`fixed: 'right'`），且操作列**建议** `resizable: false`（自适应规范 R7）。

## 9. 验收清单

提交列表页 PR 前自查（在自适应规范 §7 之外，本文额外要求）：

- [ ] 四段独立 Card，无嵌套、无合并；
- [ ] 分页**不在**表格 Card 内；`a-table :pagination="false"`；
- [ ] 工具栏左侧为 [新增][批量]、右侧为 [导入][导出][刷新]；
- [ ] `showSizeChanger`、`showQuickJumper` 均启用；
- [ ] 删除/批量删除二次确认；
- [ ] 数据请求剔除空值；远端字典只加载一次；
- [ ] 同时通过自适应规范 §7 的全部高度链验收项。

## 10. 反模式（禁止）

- ❌ 把搜索 / 工具栏 / 表格 / 分页中的任意两段塞进同一个 Card；
- ❌ **把分页放在表格 Card 内** 或使用 `a-table` 内置 `pagination`（会随表体一起滚走，破坏分页固定底部的视觉与高度链）；
- ❌ 在搜索 / 工具栏 Card 中混合彼此的内容；
- ❌ 不接入 `showQuickJumper`；
- ❌ 跳过 `loading` 态导致用户无法分辨请求状态；
- ❌ 远端字典在每次查询都重复请求；
- ❌ 用 `a-table` 自带的 column 过滤器代替搜索板块；
- ❌ 表格容器写 `overflow: auto` 或使用 `calc(100vh - 任意px)` 硬算高度（详见自适应规范 §2.3）。
