# 搜索板块相关规则

> 适用范围：所有列表页 / 树形管理页的搜索区域。

## 1. 布局与位置

- 搜索板块独立成一个轻量 **panel**（白底圆角 + 1px 阴影，非 Ant Design `Card`），与"工具栏"、"表格"、"分页"分别为相邻 panel，相互之间以 `gap-2` 留白。
- 搜索板块位于页面顶部，**紧接其下方是工具栏 panel**，再下方是表格 panel、分页 panel。
- **`查询` / `重置` 按钮 与搜索控件同行**，作为最后一个 `FormItem` 出现，不允许单独占用一整行。
- 不得把「新增 / 导入 / 导出」按钮塞进搜索 panel。

## 2. label 与控件

- 每个搜索控件**必须有 label**，label 与控件同行（`Form layout="inline"`），便于横向铺开多个字段；不得省略 label。
- 搜索控件均使用 Ant Design Vue：
  - 文本模糊搜索 → `Input`（`allow-clear`，`@press-enter` 触发查询）。
  - 下拉枚举 → `Select`（`allow-clear`）。
  - 远端字典/枚举 → `Select`（`show-search` + 自定义 `filter-option` 进行模糊搜索）。
  - 日期范围 → `RangePicker`，需提供快捷选择：本周、本月、最近一个月、本季度、上一季度、本年、上一年。

## 3. 折叠与缓存

- 当搜索字段超过一行可显示的容量时（典型 4 列以上），**默认仅展开第一行**，其他字段进入"折叠区"。
- 提供 `展开 / 收起` 按钮（位于查询/重置按钮之后），切换折叠区可见性。
- 折叠状态 **写入 `localStorage`，TTL 42h**。统一使用共享 composable：`apps/web-antd/src/views/system/_shared/use-collapse-cache.ts`，缓存 key 命名形如 `system.{domain}.searchCollapsed`。

## 4. 行为约束

- `查询`：点击或按下 Enter 时触发，重置 `page = 1` 后重新请求；
- `重置`：清空所有搜索字段并重新请求第一页；
- 所有 `undefined / 空字符串` 字段在调用 API 时必须**省略而非传空串**，避免后端误把 `""` 当作过滤条件。

## 5. 反模式（禁止）

- 不得把 `导入 / 导出 / 新增` 按钮放进搜索板块；
- 不得把 `查询 / 重置` 按钮独占一行；
- 不得在搜索控件外层使用 `a-card` 等带较大 padding 的容器（会让三段叠加吃掉过多空间），统一使用 `panel` 轻量包装；
- 不得跳过 label；
- 不得在前端列表页直接使用 `a-table` 自带 filter UI 替代搜索板块。
