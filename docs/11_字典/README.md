# 11 · 字典

> 本目录存放项目所有**枚举字典**与**错误码字典**。
> **AI 改代码时遇到枚举/状态/错误码，必先查阅这里**——避免在代码里散落魔法值。

---

## 文件清单

| 文件 | 用途 |
|---|---|
| `系统字典.md` | 业务枚举：用户状态、订单状态、单据类型等 |
| `错误码字典.md` | 全项目错误码 + message + 含义 + 触发场景 |

---

## 重要约定

### 字典与代码的关系
- 代码中**禁止散落魔法值**（`if (status === 1)`），必须用常量/枚举
- 常量/枚举的**值与含义**必须在本目录字典中可查
- 新增/修改字典时**同步更新两处**：字典文档 + 代码中的枚举

### 字典变更
- 新增枚举值 / 错误码：直接追加
- **删除枚举值**：先评估老数据怎么处理；通常软删除（标记 `[废弃]`）而不是真删
- **重命名 / 改值**：极其危险，需评估所有调用方与历史数据；走 101 优化升级工作流

### 字典与字典之间的关系
- 业务字典管"业务对象的状态/分类"
- 错误码字典管"系统抛出的错误标识"
- 两者不互相替代
