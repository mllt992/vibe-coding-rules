# 错误码字典

> 集中维护本项目所有业务错误码。
> **新增接口/错误场景时，先来这里查/加，不要散落自创。**

---

## 错误码规则

### 命名
- 全大写 + 下划线
- 格式：`<模块>_<错误>`，例：`USER_NOT_FOUND`、`ORDER_STATUS_INVALID`
- 模块前缀与业务模块名一致

### 与 HTTP 状态码的关系
- 业务错误码（4xx）→ HTTP 4xx
- 系统错误码（5xx）→ HTTP 5xx
- 表中每条都标注对应 HTTP 状态码

### 文案 / 国际化
- `message` 列默认中文；多语言项目走 i18n，文案中只列 key
- message 是面向用户的提示，**不要包含技术内部细节**（堆栈、SQL）

## 通用错误（COMMON_*）

| 错误码 | HTTP | message | 触发场景 |
|---|---|---|---|
| `COMMON_INVALID_PARAM` | 400 | 参数错误：{field} {reason} | 参数校验失败 |
| `COMMON_UNAUTHORIZED` | 401 | 请先登录 | 未登录或 token 失效 |
| `COMMON_FORBIDDEN` | 403 | 无权限执行此操作 | 已登录但无权 |
| `COMMON_NOT_FOUND` | 404 | 资源不存在 | 通用 404 |
| `COMMON_CONFLICT` | 409 | 操作冲突，请刷新后重试 | 并发冲突、乐观锁失败 |
| `COMMON_TOO_MANY_REQUESTS` | 429 | 请求过于频繁，请稍后重试 | 限流命中 |
| `COMMON_INTERNAL_ERROR` | 500 | 系统繁忙，请稍后重试。traceId: {traceId} | 未预期异常 |

## 用户模块（USER_*）

| 错误码 | HTTP | message | 触发场景 |
|---|---|---|---|
| `USER_NOT_FOUND` | 404 | 用户不存在 | 按 ID 查用户为空 |
| `USER_DISABLED` | 403 | 账号已被停用 | 登录时账号状态 DISABLED |
| `USER_PASSWORD_WRONG` | 401 | 用户名或密码错误 | **不要区分用户名错误/密码错误**（防枚举） |
| `USER_LOCKED` | 401 | 账号已锁定，请 X 分钟后重试 | 密码错误次数过多 |
| `USER_EMAIL_DUPLICATED` | 409 | 邮箱已被注册 | 注册时邮箱已存在 |

## 订单模块（ORDER_*）

| 错误码 | HTTP | message | 触发场景 |
|---|---|---|---|
| `ORDER_NOT_FOUND` | 404 | 订单不存在 | 按 ID 查订单为空 |
| `ORDER_STATUS_INVALID` | 400 | 当前状态不允许此操作（当前：{status}） | 状态机不允许此转换 |
| `ORDER_PRICE_CHANGED` | 409 | 商品价格已变更，请刷新后重试 | 下单时价格变了 |
| `ORDER_STOCK_INSUFFICIENT` | 409 | 库存不足 | 下单时库存不够 |

## 文件 / 上传（FILE_*）

| 错误码 | HTTP | message | 触发场景 |
|---|---|---|---|
| `FILE_TYPE_NOT_ALLOWED` | 400 | 不支持的文件类型 | 类型不在白名单 |
| `FILE_TOO_LARGE` | 400 | 文件大小超过限制（最大 {limit}） | 超过大小限制 |
| `FILE_VIRUS_DETECTED` | 400 | 文件检测到病毒，已拒绝 | 病毒扫描命中 |

## 新增错误码的步骤

1. 在本字典对应模块小节追加一行
2. 在代码错误码枚举类中追加常量
3. 接口文档（OpenAPI）的对应接口"可能错误"列表追加
4. 前端国际化文件追加文案（如有 i18n）
5. 提交记入 `docs/文档更新日志.md`
