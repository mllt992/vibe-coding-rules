# 系统字典

> 集中维护本项目所有业务枚举。每次新增或变更必同步本表。

---

## 字典规则

- 字典 key（存储值）建议用 `SCREAMING_SNAKE_CASE` 字符串：`ACTIVE`、`PENDING_PAYMENT`
  - 比数字 `1` / `2` 可读性强 10 倍
- 字典 label（显示值）走 i18n：`status.user.active = "在用"` / `status.user.active.en = "Active"`
- 一旦上线的字典值**不要修改**，只能新增；废弃用 `[废弃]` 标注
- 字典所在的代码常量类/枚举类，文件路径在表中写清楚

## 订单状态（order_status）

| 值 | 显示 | 含义 | 可流转到 |
|---|---|---|---|
| `DRAFT` | 草稿 | 未提交 | SUBMITTED, CANCELED |
| `SUBMITTED` | 已提交 | 等待审核 | APPROVED, REJECTED |
| `APPROVED` | 已审核 | 审核通过 | PAID, CANCELED |
| `REJECTED` | 已驳回 | 审核未通过 | DRAFT |
| `PAID` | 已支付 | 支付完成 | FULFILLED, REFUNDING |
| `FULFILLED` | 已履约 | 业务完成 | (终态) |
| `CANCELED` | 已取消 | 用户/系统取消 | (终态) |
| `REFUNDING` | 退款中 | 退款流程中 | REFUNDED |
| `REFUNDED` | 已退款 | 退款完成 | (终态) |

代码位置：（示例位）`src/.../enums/OrderStatus.java`
